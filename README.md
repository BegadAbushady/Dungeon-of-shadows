# Dungeon of Shadows

A terminal-based RPG written in Python.

## Features
- Turn-based combat
- Multiple enemies
- Random enemy encounters
- Potions
- Defense mechanics
- XP and leveling
- Stat upgrades
- Boss fight
- Replay system

## How to Run

python dungeon.py
